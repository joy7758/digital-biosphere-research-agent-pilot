# Source Record Drafts v0.1（来源记录草案）

本目录把 10 个已核验候选映射为独立 Source Record Draft（来源记录草案），供 `owner://bin-zhang` 逐项复核。原 7 项的核验见 `../source-verification-report.yaml`，新增 DBA / SAEE / DBO 三项的核验见 `../source-verification-addendum-v0.2.yaml`。

```text
Draft != Source Record
Verification != Source Approval
Recommendation != Human Decision
Source Selection != Source Validation
```

所有文件必须保持 `record_status: DRAFT_NOT_APPROVED`、`selection_decision: PENDING_HUMAN_DECISION`，直到 Human Research Owner 明确决定并另建正式 Source Record。草案不得直接加入 `context-manifest.yaml`。
